CID TERMINAL — εγκατάσταση και αλλαγές

1. Κράτησε αντίγραφο του υπάρχοντος index.html και των Firestore Rules.
2. Αντικατάστησε το index.html στο hosting με αυτό του πακέτου.
   Κράτησε τους υπάρχοντες φακέλους images/ και icons/ δίπλα του.
   Δεν περιλαμβάνονται στο πακέτο, γιατί δεν δόθηκαν μαζί με τον αρχικό κώδικα.
3. Firebase Console → Firestore Database → Rules: αντικατάστησε τα Rules
   με τα περιεχόμενα του firestore.rules και πάτησε Publish.
   Το νέο HTML και τα νέα Rules πρέπει να χρησιμοποιηθούν μαζί.
4. Κάνε σύνδεση μία φορά ως Director ή Assistant Director.
   Θα δημιουργηθεί αυτόματα η δημόσια συλλογή roster από τα υπάρχοντα users.
   Αν δεν υπήρχε ήδη config/main, ο admin μπορεί να κάνει μια αλλαγή
   στο Admin → Permissions ώστε να αποθηκευτούν οι ρυθμίσεις.
5. Κάνε hard refresh (Ctrl+F5). Έλεγξε και σε ανώνυμο παράθυρο.

Αλλαγές
- Φωτογραφίες και συνημμένα: links μόνο, χωρίς Firebase Storage και uploads.
- Matcher: επιλογή τοπικής εικόνας μόνο για ανάλυση στη μνήμη, χωρίς ανέβασμα,
  ή εισαγωγή link. Ενιαία οπτική αναζήτηση με MobileNet embeddings.
- Το MobileNet συγκρίνει χαρακτηριστικά ολόκληρης εικόνας. Δεν είναι μοντέλο
  ταυτοποίησης προσώπων ή ειδικά εκπαιδευμένο για χαρακτήρες GTA.
  Τα αποτελέσματα είναι κατάταξη ομοιότητας, όχι βεβαιότητα ότι είναι το ίδιο άτομο.
  Περιλαμβάνονται οι 40 πιο κοντινές εικόνες, ακόμη και αν η ομοιότητα είναι χαμηλή.
  Χρειάζεται internet για βιβλιοθήκες/μοντέλο. Το cache είναι προσωρινό στη μνήμη
  και περιορίζεται στις 500 εικόνες. Με ανανέωση της σελίδας ξαναδημιουργείται.
- Links για matcher: άμεσα αρχεία εικόνων, προσβάσιμα χωρίς login, με CORS.
  Σελίδες sharing δεν αποτελούν αναγκαστικά direct image links.
  Η εμφάνιση μιας εικόνας δεν εγγυάται ότι ο πάροχος επιτρέπει ανάλυσή της.
- Requests στην ενότητα Detective: πολλαπλή επιλογή πολιτών με checkbox,
  εναλλακτικά/επιπλέον ελεύθερο κείμενο για μη καταχωρισμένους στόχους.
  Το εκτυπωμένο έγγραφο γράφει REQUEST.
- Documents στο Public: επιλογή Visible to Public κατά την έκδοση/επεξεργασία.
  Μόνο τα δημόσια documents και οι directives διαβάζονται από επισκέπτες.
  Requests είναι ιδιωτικά. Τα παλιά documents χωρίς isPublic μένουν ιδιωτικά.
- Cases, organisations, interrogations: πεδίο File Number. Τα ήδη υπάρχοντα
  fileNo διατηρούνται. Δεν συμπληρώνονται αυτόματα αριθμοί σε παλιούς φακέλους.
- Roster κάτω από Directives & News, χωρίς τις κάρτες High Command.
  Ο βαθμός παραμένει διαθέσιμος στη διαχείριση λογαριασμών.
- Mobile toggle: μόνο εικονίδιο δίπλα στην ώρα της πλαϊνής μπάρας.
- Admin Map: όνομα, κατηγορία, X/Y, τύπος, διεύθυνση, χρώμα, icon,
  ακτίνα περιοχής και gallery με links, πριν και μετά τη δημιουργία location.
- Τα map locations και οι φωτογραφίες τους παραμένουν ΔΗΜΟΣΙΑ, όπως πριν.
- Νέα queries και Rules εφαρμόζουν τα δικαιώματα ανά μητρώο στη βάση.
- Ξεχωριστό δημόσιο roster χωρίς usernames. Οι agents βλέπουν δημόσια στοιχεία
  ονομάτων, βαθμών, badges και εικόνων για τις επιλογές προσώπων.
- Αποτυχία δημιουργίας εγγραφής δεν εμφανίζεται πλέον ως επιτυχία.
- Version check σε transaction αποτρέπει σιωπηλή αντικατάσταση record που
  τροποποίησε άλλος χρήστης. Σε σύγκρουση, κλείσε χωρίς αποθήκευση και άνοιξε ξανά.
- Καθαρισμός ανοιχτών φακέλων/εκτυπώσεων/αναζήτησης κατά το logout.

Έλεγχος που πραγματοποιήθηκε
- Έλεγχος σύνταξης όλων των inline JavaScript και compilation όλων των Vue templates.
- Δοκιμές με προσομοιωμένο Firestore: δημιουργία request με ελεύθερο στόχο,
  επιτυχής δημιουργία/ενημέρωση, αποτυχία αποθήκευσης χωρίς ψευδή επιτυχία,
  προεπιλογή ιδιωτικού document, διατήρηση φωτογραφιών νέου map location,
  προσθήκη photo link, δικαιώματα Probationary και queries ανά κατηγορία.
- Δεν πραγματοποιήθηκαν συνδέσεις ή εγγραφές στο πραγματικό σου Firebase.
- Δεν έγινε έλεγχος Rules σε Firebase Emulator ή πλήρης δοκιμή σε browser:
  το περιβάλλον δεν διέθετε browser και η λήψη του απέτυχε.
- Η πραγματική ποιότητα του matcher και η φόρτωση του εξωτερικού μοντέλου
  χρειάζονται δοκιμή με τις δικές σου GTA φωτογραφίες στο hosting σου.

Έλεγχος μετά την εγκατάσταση
- Επισκέπτης: βλέπει public document, directives και roster. Δεν βλέπει requests
  ή private document. Δοκίμασε δεύτερο παράθυρο για αλλαγή isPublic σε πραγματικό χρόνο.
- Director: δημιούργησε request για 2 πολίτες, εκτύπωσέ το, άνοιξέ το από δεύτερο user.
- Admin Map: δημιούργησε location με image link, κάνε refresh, έλεγξε popup/gallery.
- Permissions: βάλε έναν βαθμό σε view ή none, έλεγξε από λογαριασμό αυτού του βαθμού.
- Matcher: σύγκρινε μια ίδια, μια παρόμοια και μια άσχετη εικόνα με προσβάσιμα CORS links.

Υπάρχοντες περιορισμοί εκτός των ζητούμενων αλλαγών
- Η αφαίρεση agent ανακαλεί το profile και το roster, αλλά δεν διαγράφει το
  Firebase Authentication account. Για επαναχρησιμοποίηση του ίδιου username,
  διαχειρίσου τον παλιό λογαριασμό από το Authentication του Firebase Console.
- Το import Penal Code αντικαθιστά τις εγγραφές σε διαδοχικά batches και δεν
  διαθέτει συνολικό rollback: κράτησε αντίγραφο πριν από εισαγωγή.
- Εξωτερικά links μπορεί να λήξουν ή να διαγραφούν από τον πάροχο.
