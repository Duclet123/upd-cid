ORGANISATIONS — STATUS ΚΑΙ ΤΑΞΙΝΟΜΗΣΗ
Προστέθηκε status όπως στα Case Files: Open, Under Investigation, Pending Review,
Closed. Οι νέες εγγραφές ξεκινούν Open. Τα παλιά schemas αναβαθμίζονται κατά τη
φόρτωση, χωρίς αφαίρεση δεδομένων. Το status εμφανίζεται στις κάρτες και στο print.
Στη λίστα υπάρχει φίλτρο status, φίλτρο Lead Detective / Assigned to me και sort:
Newest first, Oldest first, Detective A–Z, Detective Z–A. Οι εγγραφές χωρίς detective
μπαίνουν στο τέλος της ταξινόμησης ανά detective. Οι ίδιοι έλεγχοι υπάρχουν και
στα Case Files. Η ενημέρωση δεν τροποποιεί τα Firestore Rules.

UPD CID TERMINAL — ΤΡΕΧΟΥΣΑ ΕΚΔΟΣΗ

ΕΓΚΑΤΑΣΤΑΣΗ / ΑΠΑΡΑΙΤΗΤΑ RULES
Το site είναι buildless HTML/JS. Η δημοσίευση γίνεται από GitHub Pages.
Κράτησε τους υπάρχοντες φακέλους images/ και icons/.
Κάνε ΝΕΟ Publish του firestore.rules στο Firebase Console → Firestore → Rules.
Η παρούσα έκδοση προσθέτει uniqueKeys και αφαιρεί τις εγκρίσεις warrants.
Χωρίς την ενημέρωση Rules δεν λειτουργούν οι νέες κρατήσεις ταυτότητας και η
επεξεργασία παλιών warrants που είχαν κλειδωθεί από προηγούμενο workflow.
Μετά τη δημοσίευση κάνε Ctrl+F5. Σύνδεση ως Director/Assistant Director
συγχρονίζει το δημόσιο roster από τα ιδιωτικά users.

ΕΡΕΥΝΑ / ΚΑΡΤΕΛΕΣ
- Citizen Registry: φωτογραφία προφίλ, ταυτότητα, επικοινωνία, σημειώσεις,
  χρονολόγιο συνδεδεμένων records και συγκεντρωτική προβολή σχετικών μητρώων.
- Το timeline χρησιμοποιεί ημερομηνία ανάκρισης ή χρόνο δημιουργίας του record.
  Τα events ταξινομούνται νεότερα πρώτα. Εμφανίζονται μόνο προσβάσιμα records.
  Δεν αποτελεί ανακατασκευή όλων των παλιών τροποποιήσεων· αυτές βρίσκονται
  στο ξεχωριστό ιστορικό κάθε record.
- Cases: χειροκίνητος File Number, Lead Detective από roster, καταστάσεις και
  φίλτρα. Η αρχική δείχνει τις ενεργές υποθέσεις που έχουν ανατεθεί στον χρήστη.
- Organisations: Lead Detective και πολλοί πολίτες με ονόματα/Citizen IDs.
- Interrogations: επιλογή Case File, πολίτη και αστυνομικού. Ο αστυνομικός μπορεί
  να επιλεγεί από roster (αποθηκεύεται και badge) ή να γραφτεί χειροκίνητα.
- Η σχέση Interrogation → Case File εμφανίζεται αυτόματα και στις δύο καρτέλες
  και στις εκτυπώσεις. Ο σχετικός Case File εμφανίζεται και στην καρτέλα του
  πολίτη της ανάκρισης. Δεν χρειάζεται δεύτερη χειροκίνητη σύνδεση.
- Cases, Organisations, Interrogations και Reports έχουν σήμανση αξιοπιστίας:
  Unconfirmed / Under Investigation / Confirmed, πηγή και ημερομηνία πληροφορίας.
  Αντίστοιχη σήμανση υπάρχει στις σημειώσεις κάθε φωτογραφίας.
- Dropdowns πολιτών και Case Files έχουν αναζήτηση και μέχρι 50 ορατά αποτελέσματα.
- Ενιαία αναζήτηση Ctrl/Cmd+K στα προσβάσιμα μητρώα, χάρτη και Penal Code.

DRAFT WARRANTS — ΧΩΡΙΣ ΕΓΚΡΙΣΕΙΣ
Τα warrants είναι αποκλειστικά drafts για προετοιμασία request.
Δεν υπάρχουν Submit / Approve / Reject ούτε ειδοποιήσεις έγκρισης.
Κάθε draft μπορεί να αφορά πολλούς πολίτες ή/και μη καταχωρισμένους στόχους.
Παλιές καταστάσεις έγκρισης δεν εμφανίζονται ως ενεργό workflow. Στην επόμενη
αποθήκευση αρχειοθετούνται σε legacyWorkflow και το record γίνεται Draft.
Τα παλιά δεδομένα και το ιστορικό δεν διαγράφονται αυτόματα.

ΔΙΠΛΟΕΓΓΡΑΦΕΣ
Έλεγχος ίδιου Citizen ID, πινακίδας και serial όπλου, χωρίς διάκριση πεζών/
κεφαλαίων και κενών. Εμφανίζεται προειδοποίηση και μπλοκάρεται η αποθήκευση
διπλοεγγραφής, με δυνατότητα ανοίγματος του υπάρχοντος record.
Οι νέες/ενημερωμένες ενεργές εγγραφές δεσμεύουν το μοναδικό identifier μέσα
στην ίδια Firestore transaction. Τα Rules επιβάλλουν την κράτηση και σε
ταυτόχρονες εγγραφές από δύο χρήστες. Αλλαγή identifier μεταφέρει την κράτηση.
Μεταφορά στον κάδο ελευθερώνει το identifier. Επαναφορά ελέγχει ξανά για σύγκρουση.
Οι παλιές εγγραφές ελέγχονται αφού φορτώσει το μητρώο και αποκτούν κράτηση όταν
αποθηκευτούν ξανά. Δεν γίνεται αυτόματο merge ή διαγραφή παλιών διπλοεγγραφών.
Identifiers δεν μπορούν να περιέχουν slash (/).

ΙΣΤΟΡΙΚΟ / ΚΑΔΟΣ
Κάθε record έχει ιστορικό αλλαγών με χρήστη, ώρα server και διαφορές πεδίων.
Εμφανίζονται οι τελευταίες 50 εγγραφές ιστορικού ανά φάκελο. Το ιστορικό είναι
ιδιωτικό, ακόμη και για public documents. Δεν καλύπτει config/users/map/Penal Code.
Η διαγραφή record μεταφέρει στον κάδο με δυνατότητα επαναφοράς.
Ο κάδος ΔΕΝ αδειάζει αυτόματα. Director/Assistant Director έχουν Permanently delete
με επιβεβαίωση: κλειδώνει την επαναφορά, διαγράφει το history και μετά το trash record.
Σε αποτυχία υπάρχει Retry. Τα εξωτερικά αρχεία εικόνων δεν διαγράφονται.
Το προαιρετικό workflow "Empty terminal trash manually" έχει μόνο χειροκίνητη
εκτέλεση. Για χρήση του απαιτείται FIREBASE_SERVICE_ACCOUNT secret για cid-upd.
Δεν χρειάζεται secret για το κουμπί Permanently delete μέσα στο site.

ΕΚΤΥΠΩΣΗ / ΥΠΟΓΡΑΦΕΣ
Logo αριστερά, Criminal Investigation Division μεγάλο, Unified Police Department
από κάτω. Lead Detective και πολίτες πρώτα, με όνομα και Citizen ID.
Το Transcript είναι η τελευταία ενότητα περιεχομένου πριν τις υπογραφές.
Οι εικόνες φαίνονται ολόκληρες. Το timestamp είναι στο τέλος χωρίς TS.
Πρώτη υπογραφή: ο τρέχων συνδεδεμένος χρήστης, ανεξάρτητα από rank.
Δεύτερη υπογραφή: ΠΑΝΤΑ ένας διαθέσιμος Director/Assistant Director του roster,
δίπλα στην πρώτη, χωρίς να αποτελεί ένδειξη έγκρισης warrant.
Οι Directors εναλλάσσονται σε τυχαία σειρά. Με δύο ή περισσότερους αποφεύγεται
συνεχόμενη επανάληψη. Με έναν διαθέσιμο χρησιμοποιείται αυτός· χωρίς κανέναν
η θέση παραμένει κενή αντί να επινοηθεί όνομα. Η επιλογή είναι σταθερή στην ίδια
προεπισκόπηση. Μπορεί να εμφανιστεί το ίδιο πρόσωπο και στις δύο θέσεις αν ο
εκτυπωτής είναι Director και επιλεγεί και στη δεύτερη.
Δεν υπάρχει μαζική εκτύπωση ούτε print στα Directives & News.
Για καθαρό PDF: Print → More settings → Headers and footers OFF. Η αρίθμηση
του εγγράφου διατηρείται μέσω CSS page counters σε Chrome/Edge.

ΚΕΙΜΕΝΑ / ESC
Εργαλεία bold, italic, underline, heading, λίστες, quote, link, Clear και Preview
στα μεγάλα πεδία κειμένου και templates. Ctrl/Cmd+B, I, U. Αποθηκεύεται συμβατό
κείμενο με ασφαλή σύνταξη μορφοποίησης, χωρίς εκτέλεση raw HTML.
Esc κλείνει ένα ορατό επίπεδο κάθε φορά. Σε record καλεί την ίδια closeRec με το X,
περιλαμβάνοντας την αποθήκευση υπάρχουσας επεξεργασίας. Dropdowns κλείνουν πρώτα.

ΕΙΚΟΝΕΣ / MATCHER
Εικόνες και αρχεία με links, χωρίς Firebase Storage. Τοπική εικόνα αναζήτησης
matcher αναλύεται στη μνήμη χωρίς upload. Η ομοιότητα είναι διερευνητικό βοήθημα,
όχι πιθανότητα ταυτοποίησης. Απαιτούνται άμεσα image URLs που επιτρέπουν CORS.
Υπάρχει σύγκριση εικόνων δίπλα δίπλα και άνοιγμα του σχετικού record.
Map locations και φωτογραφίες τους παραμένουν δημόσια όπως πριν.

ΔΟΚΙΜΕΣ
npm install && npm test (δεν απαιτείται build για τη λειτουργία του site).
Τα Node tests χρησιμοποιούν προσομοιωμένη Firestore και δεν γράφουν στην παραγωγή.
Για πραγματικά Rules tests σε απομονωμένο τοπικό Firestore Emulator:
FIRESTORE_EMULATOR_JAR=/path/emulator.jar python tests/run-firestore-rules.py
Το test χρησιμοποιεί μόνο localhost/demo-cid, ποτέ cid-upd.
Ελέγχονται μεταξύ άλλων: drafts χωρίς εγκρίσεις, ιδιωτικό history, perm delete,
normalized uniqueness, ταυτόχρονες διπλές εγγραφές και συγκρούσεις επαναφοράς.
Δεν έγινε πλήρης οπτική δοκιμή στον browser. Η ποιότητα matcher/CORS χρειάζεται
δοκιμή με τις πραγματικές GTA εικόνες στο hosting.
